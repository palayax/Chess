Natural wording (optional) — the wording model and the code that runs it.

Natural wording is off unless you turn it on. If you download the wording model (at setup or in Settings), the
app runs it on your phone to reword its own commentary. Every fact in a reworded sentence is checked against the
app's own text, and the original is kept if anything differs. Nothing you do is sent anywhere.

==============================
Wording model — Qwen2.5-1.5B-Instruct (GGUF, Q4_K_M)
==============================
Model: Qwen2.5-1.5B-Instruct, quantized to Q4_K_M in the GGUF format, file qwen2.5-1.5b-instruct-q4_k_m.gguf,
as published by the Qwen team in the official repository
https://huggingface.co/Qwen/Qwen2.5-1.5B-Instruct-GGUF (commit 91cad51170dc346986eccefdc2dd33a9da36ead9).
The app downloads an unmodified copy of that file from the app's own GitHub release; it is not changed,
re-quantized or fine-tuned.
